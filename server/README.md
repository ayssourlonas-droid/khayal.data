# khayal-stats — سيرفر الإحصاء والأخطاء

بديل Worker كلاودفلير. نفس الواجهات التي يستعملها التطبيقان، فلا يتغير كودهما إلا رابط الإحصاء.
الحالة في الذاكرة وتُحفظ كل 10 دقائق (إن تغيّرت) وعند الإيقاف في `stats/stats.json` داخل `khayal.data`، وتُقرأ منه عند التشغيل.

## أين يوضع الكود

داخل **`khayal.data` نفسه** في مجلد `server/` (هذا المجلد). لا حاجة لمستودع جديد.
الملف المحفوظ `stats/stats.json` خارج `server/`، فلا تعيد لقطات الإحصاء نشر السيرفر
(Render ينشر تلقائياً فقط حين تتغير ملفات تحت مجلد الجذر المحدد).

## النشر على Render (من الهاتف)

1. ارفع هذا المجلد `server/` كما هو إلى جذر `khayal.data`.
2. في Render: New ← Web Service ← اربط مستودع `khayal.data`، والفرع `main`.
3. الإعدادات:
   - Language = Python
   - **Root Directory = `server`**
   - Build Command = `pip install -r requirements.txt`
   - Start Command = `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - Instance Type = Free
   - Advanced ← Health Check Path = `/health`
4. Environment (المتغيرات):

| الاسم | القيمة |
|---|---|
| `STATS_TOKEN` | كلمة سر طويلة تخترعها. تضعها لاحقاً في إعدادات المتحكم |
| `HASH_KEY` | سر طويل ثابت. **لا يتغير أبداً بعد اليوم** (تغييره يجعل كل الأجهزة «جديدة»). احفظ نسخة منه |
| `GH_TOKEN` | توكن Fine-grained **خاص بهذا السيرفر**: مستودع `khayal.data` فقط، وصلاحية Contents (قراءة وكتابة) فقط |
| `GH_REPO` | `ayssourlonas-droid/khayal.data` |
| `GH_BRANCH` | `main` |
| `GH_PATH` | `stats/stats.json` |
| `FLUSH_SECONDS` | `600` |

   لا تستعمل توكنك الواسع هنا: Render طرف ثالث.

5. بعد أول نشر افتح `https://<اسم-الخدمة>.onrender.com/health` فيجب أن ترى `ok`.

## منع النوم (cron-job.org)

مهمة جديدة: العنوان `https://<اسم-الخدمة>.onrender.com/health`، الطريقة GET، كل **10 دقائق**
(الخدمة المجانية تنام بعد 15 دقيقة بلا طلبات). هذا حل التفافي لا تضمنه Render رسمياً.

## ربط التطبيقين

- خيال: في `games_app/lib/config.dart` اجعل `statsUrl` = رابط الخدمة (بلا `/` في الآخر).
- المتحكم: الإعدادات ← رابط الإحصاء = الرابط نفسه، و`STATS_TOKEN` = قيمة المتغير في Render.

الأرقام تبدأ من الصفر (لا نقل من الـWorker القديم).

## ما يُخزَّن (والملف عام)

أرقام مجمَّعة فقط: فتح كل لعبة يومياً، وعدد الأجهزة يومياً، وبصمات HMAC مقتطعة (12 خانة) بدل المعرّفات العشوائية، وبلاغات الأخطاء
مجمَّعة بالبصمة (نوع الخطأ ورسالته مقصوصة ومنظَّفة من الروابط والبريد، وأول أسطر مكان الوقوع، وطراز الجهاز وإصدار أندرويد).
لا تُخزَّن عناوين IP. بما أن نقاط الاستقبال مفتوحة فبوسع أي أحد إرسال نص عشوائي كبلاغ خطأ؛ يُنظَّف ويُقصّ ويُحدّ عدده (500 خطأ مميّز)،
لكنه سيظهر في ملف عام. الحل الجذري لاحقاً: مستودع خاص لهذا الملف (يتغير `GH_REPO` فقط).

## حدود (الخدمة المجانية)

- بعد إعادة تشغيل مفاجئة تضيع أرقام آخر ≤10 دقائق.
- إن تعذّر تحميل اللقطة عند التشغيل يتوقف السيرفر (عمداً) كي لا يكتب فوق البيانات، وتعيد Render تشغيله.
- حد معدل: 120 طلباً/دقيقة لكل عنوان IP.
